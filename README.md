# ww · 人主导的人机协同

> 以现实与证据为基础，以人的自主性为底线，通过人机协作增强理解、判断、创造与行动能力。

这是一个关于人机协同与决策方法的探索项目。当前版本记录愿景、原则与评价标准，不是已经完成的多智能体软件，也不承诺多模型协作必然优于单模型或人的独立判断。

## 为什么做这个项目

我们希望把对命运的折服、对运气的迷信，转化为依据现实情况、逻辑与可检验因果关系形成判断的努力。

这不意味着随机性不存在，也不意味着一个听起来合理的解释就已经证明了因果。我们关心的是：哪些事情可以理解和改变，哪些仍然不确定，以及什么证据会使我们修正判断。

## 愿景：能力深度协同，人的主体性不被取代

我们探索一种能力深度协同、人的主体性不被取代的人机合作方式。

让人的现实经验、价值判断与 AI 的分析、质疑和创造能力相互补充，增强理解现实、形成选择和采取行动的能力。人始终保留形成和改变目标、理解并反对建议、撤回委托及退出协作的权利。

“人机合一”是深度协作的愿景，不是意识融合或超常能力已经实现的声明。项目既关注协作是否增强能力，也关注人是否仍然掌握方向。

我们追求的协作不是让人服从机器，也不是让 AI 只会附和人，而是通过持续交流、相互校正，形成新的理解与选项。

## 核心原则

### 1. 目标由人形成，也可以改变

AI 可以帮助澄清目标、质疑前提和指出矛盾，但不能把自己的推测写成“人真正想要的东西”。重要的价值取舍与生活方向，不能被系统默认值或自动化流程代替。

### 2. 重要判断应当能够理解、检查与挑战

建议应说明关键证据、假设、代价、不确定性与替代选项，并指出什么变化会使判断失效。模型的名气、表达的流畅程度或多个模型的一致意见，都不能代替理由。

### 3. 保留合理异议

AI 不以迎合人为目标，人也不必服从 AI 的一致意见。保留有依据的少数意见、不同解释与未解决分歧，不为了得到整齐的结论而抹平它们。

### 4. 委托有边界，而且可以撤回

自主性不等于所有事情都亲自处理，而是知道委托了什么、能够监督，并能够收回。一次许可不能自动扩展为永久或无限的代理权；涉及资料、费用与现实行动的授权应当明确。

### 5. 可以退出，也可以接续

重要资料、判断依据与结果应以人可以阅读和迁移的形式保留，不把协作建立在某个模型不可检查的记忆上。退出或更换工具，不应意味着失去理解既有工作的能力。

## 如何判断协作是否有用

同时检查两件事：

| 评价方向 | 需要观察的问题 |
| --- | --- |
| **能力增强** | 是否发现了遗漏、形成了有效的新选项、减少了可避免的错误，或降低了不必要的负担？ |
| **主体性保留** | 人是否理解重要理由、能够表达自己的价值取舍、反对 AI，并在必要时不依赖它作出选择？ |

这些是需要在实践中检验的标准，不是项目已经取得的成果。

如果答案越来越漂亮，但使用者越来越不理解、不敢反对或无法退出，这不算成功。评价也不以模型数量、讨论轮数或意见一致程度代替实际效果。

## 与 ww决策机构实践的关系

ww决策机构可以是这一理念的一种实践，不必承载它的全部。

本仓库用于记录和修正理念与方法，不自动成为任何现有系统的新运行规则。多模型委员会是一种可选的研判方式，不是所有问题都必须采用的流程；项目也不绑定某个模型、笔记软件或 Agent 平台。

是否采用新流程、调用模型、扩大资料范围或执行现实行动，应在具体实践中另行确认，而不是由这份愿景声明推导出授权。

## 当前范围与资料边界

- 当前先保留愿景与原则；方法、模板和案例可以在实际使用后逐步补充。
- 不把尚未验证的自动化能力或效果写成已经完成的功能。
- 不上传个人画像、账本、完整聊天、凭据、本机配置或未经审阅的私人案例。
- 后续若收录案例，应区分事实、模型意见、人的决定、现实结果与复盘修正，并在上传前完成必要的授权和隐私检查。

**让协作增强人的能力，而不是取代人掌握方向。**
